# Clonhero

A browser-based 3D roguelike shooter built with Three.js. Fight through procedurally generated rooms, level up, and build powerful ability combinations across three stages.

## Play

[Play Online](https://abeles.dev/clonhero) | Desktop & Mobile supported

## Features

- 33 upgradeable abilities with elemental synergies
- 6 enemy types including multi-phase bosses
- Procedural room generation with scaling difficulty
- Local scoreboard tracking

## Development

```bash
npm install
npm run dev
```
